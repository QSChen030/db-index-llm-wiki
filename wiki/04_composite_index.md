# 04. 複合索引與最左前綴原則
## 核心定義
複合索引（Composite Index）是同時將多個欄位組合建立在同一個 B+ Tree 上，其查詢生效條件必須遵守「最左前綴原則（Leftmost Prefix Principle）」。
## 生活化比喻
就像電話簿先按「姓氏」排序，同姓氏再按「名字」排序。如果你只知道「姓陳」，可以快速縮小範圍；但如果你只知道名字叫「卿順」卻不知道姓什麼，整本電話簿的排序就派不上用場。
## 運作原理
- 假設建立複合索引 `(A, B, C)`，B+ Tree 會先依 `A` 排序，`A` 相同再依 `B` 排序，最後依 `C` 排序。
- 查詢條件包含 `A`、`A+B` 或 `A+B+C` 時都能命中索引；但若跳過 `A` 直接查 `B` 或 `C`，索引就會失效。
